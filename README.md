# Supernoova — Game Landing Page

A responsive, space-themed product landing page introducing **Supernoova**, a game concept.

## Features
- Cosmic dark theme, animated starfield, floating planet, orbital details, and gradient accents
- Product-style hero section, universe showcase, feature cards, and project CTA
- Scroll reveal animations and scroll progress indicator
- Responsive mobile navigation and layouts
- Reduced-motion accessibility support
- Built with plain HTML, CSS, and JavaScript — no build step required

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Preview
Enable GitHub Pages from **Settings → Pages** and select the `supernoova-space-redesign` branch as the source to preview this redesign. The existing `main` branch remains unchanged.

## Note
This is a promotional concept page. Game mechanics, release dates, and availability are intentionally not claimed as confirmed details.
